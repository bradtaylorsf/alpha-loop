## What Worked
- Implemented a fail-closed merge gate that waits for checks, blocks failed or empty rollups by default, and preserves unmerged worktrees.

## What Failed
- Initial implementation allowed `on_timeout: warn` to bypass the 10-second minimum PR age.

## Patterns
- Treat absent, pending, failed, and successful checks as distinct states; only confirmed success should authorize merging by default.

## Anti-Patterns
- Treating an empty check rollup or elapsed timeout as equivalent to checks passing.

## Suggested Skill Updates
- Update testing guidance to require boundary tests for fractional configuration values and interactions between fail-open settings and invariant safety floors.
