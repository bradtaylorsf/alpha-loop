## What Worked
- Added a pre-session liveness probe that aborts before creating session, git, worktree, label, or PR state when the configured agent is unavailable.

## What Failed
- Initial implementation missed authentication failures during repair, review, verification, and batch-review stages; the critical review finding was fixed before completion.

## Patterns
- Perform external-tool liveness checks immediately before the first persistent mutation.

## Anti-Patterns
- Treating authentication or agent-spawn failures as ordinary per-issue failures burns the remaining queue.

## Suggested Skill Updates
- Update the implementation-planning skill to require an inventory of every invocation path for shared external dependencies, including retry, repair, review, and verification stages.
