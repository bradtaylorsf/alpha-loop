# Issue #392: review artifacts are mandatory gate evidence

## What happened

A canceled post-session review agent did not write `review-session.json`. The
orchestrator interpreted the missing artifact as a passing review and continued
finalization. The same default was shared by issue and batch review paths.

## Root cause

The default gate object encoded `passed: true` for missing or invalid files,
and exhausted review loops did not propagate their final failed gate into test,
merge, or session status.

## Prevention

- Missing or invalid review artifacts produce a critical failed gate.
- Exhausted issue and batch reviews mark the pipeline unsuccessful and block
  auto-merge.
- Exhausted post-session reviews add a durable session failure and nonzero exit.
- Only an explicit review-skip configuration may proceed without gate evidence.
- Verification retains its explicit runner-result fallback when no optional
  verification JSON is produced.
