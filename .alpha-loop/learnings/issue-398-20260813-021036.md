# Issue #398 epic verification evidence learning

- GitHub's `closes:#N` PR search is fuzzy: a result may merely mention `#N`.
  Resolve merged closing declarations from issue timeline cross-references and
  exact closing-keyword matches, with a filtered search only as fallback.
- A merged diff proves implementation but not every acceptance execution gate.
  Supply bounded PR bodies, check conclusions, and issue verification comments
  as explicitly untrusted evidence alongside the diff.
- A verify-only agent is producing the final verdict. Criteria that name that
  same invocation must evaluate the other assertions and treat the current run
  as the command execution, or the first successful pass becomes circular.
